# 0. PURPOSE

This document defines the MINIMUM VIABLE PRODUCT (MVP) for Uzum Wallet:
- Multi-currency balances (UZS + USD in MVP)
- Internal peer-to-peer transfers (P2P)
- FX conversion (quote + execute)
- Admin ledger operations (fund/mint, withdraw/burn, reverse, create/close)
- Transaction history + receipts
- Sandbox spend simulation (internal-only)

OUT OF SCOPE FOR MVP (explicit):
- KYC onboarding / verification
- External rails (card/bank top-ups and withdrawals)
- Merchant checkout integration (real acquiring)
- Holds/authorize/capture for card/merchant spend
- Chargebacks/disputes flow
- Credit / BNPL / lending
These appear in the Roadmap document.
